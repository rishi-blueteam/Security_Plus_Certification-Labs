# CompTIA Security+ Practical Labs

This repository documents hands-on labs and practical exercises completed as part of my CompTIA Security+ preparation. It serves as a record of my learning, technical exploration, and practical engagement with security concepts across the certification domains.

## Domains Covered

- **Domain 1:** General Security Concepts, Threat Actors, and Security Controls
- **Domain 2:** Social Engineering and Phishing Analysis
- **Domain 3:** Malware Analysis
- **Domain 4:** Cryptography
- **Domain 5:** Security Architecture and Infrastructure
- **Domain 6:** Vulnerability Management
- **Domain 7:** Data Breaches
- **Domain 8:** External Attack Surface Management (EASM)
- **Domain 9:** Security Auditing

## Repository Purpose

The repository is intended to maintain a structured collection of completed labs and exercises, providing a practical reference for revisiting concepts and tracking continued development across different areas of cybersecurity.

*This repository reflects practical learning and lab-based exploration undertaken during Security+ preparation.*
